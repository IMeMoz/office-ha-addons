# Office HA add-ons

Small Home Assistant OS add-ons:

- **label_printer**: shares a USB label printer on TCP 9100 (raw/JetDirect).
- **bt_speaker**: pairs a Bluetooth speaker through the host's BlueZ and keeps it connected so the HA OS audio service can use it.

Add this repository in Settings > Add-ons > Add-on store > three dots > Repositories.
